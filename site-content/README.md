検証:
- トップページと新規2ページはHTTP 200、PHP警告なし。
- 新規ページのPC 1440px・スマートフォン390px表示は横はみ出しなし。
- トップページ・新規ページに運営者情報、編集方針、問い合わせへのリンクを確認。
- フォームは表示確認のみ。メール送信テストは行っていない。
- jQuery関連の外部CDNは検証環境のネットワーク制限により取得できず、それに依存する動作は未検証。
- 新規固定ページにはCocoonの既存レイアウトを使用。テーマのSNSボタン等は変更していない。
