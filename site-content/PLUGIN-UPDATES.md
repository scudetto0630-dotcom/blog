# 専用プラグインの更新

1.4.0から、管理者がこのZIPをインストールすると、既存の接続キーで
`POST /hirogaru/v1/plugin-update` を利用できます。
対象は `hirogaru-home` のみです。他のプラグインの管理APIはありません。
このキーでPHPプログラムを変更できるため、秘密情報として管理してください。
無効化は「外観 → ひろがるトップページ → 編集接続を無効にする」。

更新要求は `commit`（40桁の確定コミット）、`sha256`（ZIPのSHA256）、
`expected_version`（直前にstatusで確認した現在版）のみ。
取得先は当リポジトリのraw.githubusercontent.com固定。リダイレクトは禁止。
ZIPのサイズ・展開サイズ・パス・重複名・シンボリックリンク・メインファイル・
バージョン上昇を検証します。WordPress 6.3以降、直接書き込み、ZipArchiveが必要です。
WordPress標準アップグレーダーの一時バックアップを利用します。
サーバー停止や更新PHP自体の不具合からの完全自動復旧は保証しません。
更新前にConoHa側のバックアップを確認し、更新後は必ず別リクエストでstatusと公開ページを検証します。
並列更新をロックし、成功時にコミット・ハッシュ・時刻を保存します。
異常終了でロックが残った場合は管理者による調査が必要です。

初回1.4.0導入は、現在の1.2.0にファイル更新権限がないため管理画面での置き換えが必要です。
プラグインを削除・停止せず「現在のものと置き換える」を使用します。
キーの再発行は不要です。

検証：PHP-WASMで81件（既存68件を含む）のテスト成功。
アップデーターの検証テストは入力・ZIP検査の単体テストです。
実WordPressでのファイル置換・標準ロールバックは未検証です。
本番の初回導入後に利用条件と通信を確認してから更新を行います。
