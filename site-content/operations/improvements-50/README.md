# 50項目の対応表

記事の整理、読者向け機能、デザイン、管理・検索機能をまとめて改善。検索実績や案件がないものは準備済みとして区別します。

| 番号 | 改善 | 状況 | 内容 |
|---|---|---|---|
| 1 | 記事の薄い段落を削る | 実装 | 13記事の重複を整理。3本の長文手順は同じ説明をまとめ、旧IDを対応する節のアンカーとして保持。 |
| 2 | 記事の冒頭で答えを伝える | 実装 | 選び方・準備・AI確認・CSVなど8記事の冒頭を具体的な答えへ。体験記事は本人の感想を先に置く。 |
| 3 | 体験談と解説の配分を見直す | 実装 | データ加工の体験と架空例を早い段階で区別。毎日の手順と誤読される説明を修正。 |
| 4 | タイトルの似た言い回しを減らす | 実装 | 購入体験、仕事の内容、仕事までの経緯の3タイトルを短く自然に整理。 |
| 5 | 記事の終わり方を自然にする | 実装 | 繰り返す教訓を削り、仕事記事は本人が気に入っている働く場所の話へ戻す。 |
| 6 | まんもすの記事を写真付きの連載にする | 実装・下書き | 猫カテゴリーに写真で読む日常3テーマの入口。実際の写真・本人の発言で私用の連載メモを準備し、薄い類似記事は量産しない。 |
| 7 | 猫用品にまんもすの場合を添える | 実装 | キャリーの買い替え、体重、紙砂や居場所の好みを保持。一般論を減らし、本人の猫の条件が分かる説明を優先。 |
| 8 | ウイスキーの感想を短いカードにする | 実装 | 4本の確認済みの感想と選んだ理由をカード表示。未確認の香味や比較順位を足さない。 |
| 9 | 購入理由と飲んだ感想を分ける | 実装 | グラス付きがきっかけ、今は香りが好き、という流れを整理。飲み方の重複も統合。 |
| 10 | IT記事に操作前後の具体例を増やす | 実装 | 3行の架空表、抽出後のID、日付順の結果、実際に頼める依頼文を追加。 |
| 11 | スマホの記事一覧を見直す | 実装 | 横に写真と本文を置くコンパクトなカード。長いタイトルも折り返し、説明は2行まで。 |
| 12 | 横長写真と縦長写真の配置を使い分ける | 実装 | 縦写真の全体表示を保ち、拡大画面では余白内に収める。カードの小さい枠でも無理に切らない。 |
| 13 | 写真一覧に絞り込みを付ける | 実装 | 顔・表情、くつろぐ、寝姿、爪とぎの上。元の17枚を重複させずに分類。 |
| 14 | 写真をタップして大きく見る | 実装 | 前後移動、矢印キー、Escape、閉じた後のフォーカス復帰。絞り込み中は表示対象内で移動。 |
| 15 | 写真まわりの余白を統一する | 実装 | 写真・説明・見出し・カードの間隔を調整。写真下の定型ラベルは戻さない。 |
| 16 | カテゴリーごとに最初のおすすめを選ぶ | 実装 | まんもすの暮らし、グレンリベット購入体験、実際のデータ加工の仕事を入口へ。 |
| 17 | 関連記事の案内を読む目的に合わせる | 実装 | 選ぶ前、飲んだ感想、手順を試すなど、リンク先の役割を明示。 |
| 18 | 続きから読む | 実装 | 読んでいた位置を端末内に記録。本人がボタンを押したときだけ移動し、90日で整理。 |
| 19 | 記事のお気に入り保存 | 実装 | 登録不要の端末内保存と保存一覧。個別削除・全削除・読書位置だけの削除に対応。 |
| 20 | 検索結果に該当する文章を出す | 実装 | 本文の検索語に近い箇所を抜粋。白州・写真一覧などの公開固定ページも検索対象へ。 |
| 21 | 実際の検索語と記事を照合する | データ待ち・準備済み | 既存CSV取込に、対象ページの記録と実績確認画面を追加。Googleの実績は未取得。 |
| 22 | 表示されてもクリックされない記事を直す | データ待ち・準備済み | 表示回数・クリック率からの候補を確認できる画面。データなしで対象記事や数値を作らない。 |
| 23 | 読まれ始めた記事の関連内容を充実させる | データ待ち・準備済み | 同じ長さの重ならない2期間で候補を抽出する機能。関連内容の拡充は実データを見て判断する。 |
| 24 | 画像の配信サイズを端末に合わせる | 実装 | 32点に小さい配信画像、うち6点に中間画像。srcsetとsizesで必要なサイズを選択。原本は保持。 |
| 25 | 表示速度を実測して改善する | 実装 | 同じ検証用ブラウザーで画像容量・LCP・レイアウトのずれを前後比較。実利用者のCore Web Vitalsとは区別。 |
| 26 | 案件候補を記事との相性で整理する | 案件待ち・準備済み | 私用管理欄と記事ごとの相性メモ。未提携の案件を提携済みにはしない。 |
| 27 | 案件前の体験メモを用意する | 準備済み | 使用前の状態、期待、試す条件、記録日の欄。過去の体験を新たな実験として書き直さない。 |
| 28 | 商品リンクを置く位置を考える | 案件待ち・準備済み | 理由・向く条件・良い点と合わない点の説明後へ置く掲載手順を用意。広告リンクは未登録のまま。 |
| 29 | 使用後の変化を追記する | 準備済み | 追記日・使用期間・変化・写真ID・未確認のことを残す管理欄。実際の経過はまだ作らない。 |
| 30 | 改善前後を比べる記録 | 実装 | 本文の指紋、実際の到達件数、取込済み検索実績を最大12回分。期間条件を確認して比較する。 |
| 31 | メニューと現在地を分かりやすくする | 実装 | 記事・カテゴリー・写真・感想ページに対応した現在地表示。保存一覧への入口も追加。 |
| 32 | サイトのロゴを整える | 実装 | 暖色の猫のマークと読みやすい文字を組み合わせ、各ページのヘッダーを統一。 |
| 33 | ファビコンを作る | 実装 | SVGと32pxアイコン、スマホのホーム画面向け180pxアイコン。 |
| 34 | ボタンの見た目を統一する | 実装 | 色、枠、角丸、押した状態、フォーカス表示を統一。 |
| 35 | スマホで押し間違えにくくする | 実装 | 主な操作を44px以上の押せる範囲へ。狭い画面ではメニューを2列に整理。 |
| 36 | 本文と背景の読みやすさを点検 | 実装 | 文字の濃さ、注釈の最小サイズ、写真上の説明の背景を調整。 |
| 37 | キーボード操作に対応 | 実装 | 写真の開閉、前後移動、フォーカス保持・復帰、目次、横長の表を確認。 |
| 38 | 動きを控えたい設定に対応 | 実装 | 端末のreduced-motion設定でアニメーションと滑らかな移動を抑制。 |
| 39 | 目次を開閉しやすくする | 実装 | キーボードで押せるボタンと開閉状態。スマホは初めからコンパクトにして表示の跳ねを抑える。 |
| 40 | 読む位置が分かる表示 | 実装 | 長い記事だけに細い進捗バー。スクリーンリーダーへの連続通知は行わない。 |
| 41 | 表をスマホで扱いやすくする | 実装 | 実際にはみ出す表だけに横スクロールの案内とキーボード操作を付ける。 |
| 42 | 404ページを作り込む | 実装 | 検索、カテゴリーの説明、保存した記事、トップへ戻る案内。HTTP404は維持。 |
| 43 | 検索結果なしの案内を改善 | 実装 | 検索語に合う別の言葉と、カテゴリーへの入口を提示。 |
| 44 | 絞り込み条件をURLに残す | 実装 | 写真の条件を再読み込み・戻る操作後も維持。直接開いた場合はサーバーでも初期反映。 |
| 45 | フォームのエラーを近くに表示 | 実装 | 入力欄のそばに説明し、最初のエラーへ移動。失敗時に内容を消さず、既存の問い合わせフォームも尊重。 |
| 46 | 公開前のプレビュー環境 | 実装 | 本番のPHPヘルパー・CSS・JSを使うローカル確認画面。フォーム送信と通信はCSPで無効化。 |
| 47 | 古いURLから正しいページへ案内 | 実装・登録なし | 管理記事への転送だけを登録できる機能。既存URLは変えず、標準の旧スラッグ転送も保持。 |
| 48 | 薄い自動一覧の検索対象を整理 | 実装 | 日付・著者と薄いタグ一覧をnoindex。カテゴリーは維持。端末内の保存一覧はnoindexでサイトマップから除外。 |
| 49 | 構造化データを点検 | 実装 | JSON-LDの構文、記事名・画像・著者・日付と実ページの整合性をローカル照合。Googleの検証を代行したとは扱わない。 |
| 50 | 孤立した記事を探す | 実装 | 公開ページ間のリンクグラフとアンカーを検査し、入口がない記事を検出するツール。 |

ローカルプレビューは `tools/build-reader-preview.py` で作成します。送信・通信を無効にした確認用画面で、WordPress管理画面やデータベース全体の複製ではありません。
