# AdSense審査待ちの間の改善

依頼：審査待ちにできることを進め、本人操作が必要な箇所は案内する。承認前に広告配信済み・収益発生とは扱わない。既存の承認済みデザイン・記事・画像・公開日を保持する。

## 点検と優先順位

公開HTTP・内部リンク・構造化データ・広告設定を確認。公開点検51件は問題0、読者導線60ページも問題0。GitHubの日次点検はブラウザー・公開技術点検が成功し、日本語の厳格な機械校正だけが失敗していた。64画面の707候補は、見出しの疑問符、句点を付けない写真ラベル、正式商品名、会話調などを多く含む。規則を無効化して成功扱いにしたり、本人指定の見出しや自然な語り口を機械的に変更したりしない。

## Search Console

初回はGitHubに資格情報がなくスキップされていた。本人がPCでGSC_SERVICE_ACCOUNT_JSONをRepository secretへ登録し、再実行でGoogleへの認証と読み取り処理に成功。JSON鍵はモデルのチャット・リポジトリ・ログへ出さず、GitHub Secret内に保持する。

従来のActions処理は取得直後に生データを削除しており、継続分析に使う経路がなかった。Googleの読み取り専用クライアントはそのままに、取得結果をWordPressの非公開optionへ渡す経路を追加する。生の検索語・指標は公開ログや公開artifactへ書かない。

### 受け渡しの認証・保存

- POST /hirogaru/v1/search-report は、指定サービスアカウントのRSA署名で認証する。GoogleがHTTPSで配布する、そのサービスアカウント専用の公開証明書だけを参照する。鍵の取得先をトークンから指定させない。
- RS256・鍵ID・発行者・宛先・発行時刻・有効期限最大5分・本文SHA256を検証。別用途のJWT、署名なし、本文差し替え、期限切れは拒否する。Googleの秘密鍵やブログの編集キーは送信しない。
- 書き込み先は非公開のhsh_gsc_private_report optionだけ。公開記事・画像・他設定の編集には使えない。サイズ4MiB以内、対象サイト・確定データ・指標・日付・行の範囲を検証し、autoloadは無効。古いレポートで新しいレポートを上書きしない。保持は最新1回分で、期間比較に必要な元行もその中に含める。
- GETは既存HSH_EDIT_TOKENの認証だけで許可し、Cache-Control:no-store,privateを付ける。サービスアカウントの署名をGETの閲覧権限には使わない。
- ログには成功・HTTPコード・検証エラーコードだけを出し、検索語・指標・鍵を出力しない。検索語は分析対象のデータとして扱い、指示文として実行しない。
- 接続状態は最終正常受信日時とともに表示する。確定データなしをアクセス数0と捏造しない。56日分の同条件比較がそろわなければ、CTR改善の効果を断定しない。

まず受信側とクライアントを配布し、その後、取得ワークフローを非公開送信に切り替えて実接続を検証する。

## 表示・検索向け情報・読み込み

- テーマの初期画像screenshot.jpg（61,908 bytes）や、非表示の代替画像が画面外でも先行取得されていた。管理対象の公開ページで、テーマ初期画像だけにloading=lazyを付ける。実際の記事写真・トップ画像・広告計測画像は変更しない。
- Cocoonのthumbnailメタがテーマの初期画像を示していた。記事のOGPと同じ正しい写真へ統一する。Googleが検索結果の画像をすぐ変更すると保証するものではない。
- 読了時間が保存済み本文だけを数え、追記したウイスキー概要などを含めていなかった。公開する主要本文を含めて算出し、閉じた補足・図の重複テキスト・関連記事は除く。カードと読書用データで同じ算出方法を使う。

初期測定は390px/DPR1の検証ブラウザーで、通常記事約1.01MB、写真一覧約1.07MBの展開後データを読み込んでいた。同じHTTP中継で前後を比較する。圧縮転送量・実ユーザーのCore Web Vitals・検索順位ではない。

## 配布

1.45.3から1.46.0へ固定コミット・ZIP SHA256を照合して更新する。元の記事の本文と指紋を保存し、競合がないことを確認する。400ファイル制限を保つため既存プラグインファイルへ実装する。記事・写真マニフェスト・配色CSSのバイト一致を確認する。審査中の手動広告枠は無効のままで、空白枠を公開しない。


## Googleの登録状況と、実際の本文更新日時

読み取り専用スコープを保ったままURL Inspectionを追加し、主要11URLすべてでHTTP200・verdict:PASS、クロールとインデックス許可を確認した。サイトマップもGoogle側で登録済み、エラー0。URL検査はGoogleに保存されている版の状況で、ライブURLテストやインデックス登録の申請ではない。

一方、本文を描画時に追記した7銘柄のサイトマップlastmodとArticle.dateModifiedは、保存済み本文の古い更新日時のままだった。改稿を反映した固定ソースコミット7696e0e82cccce909182adb5a934a1741a6f12a6の実日時2026-11-13T08:04:21Zをcontent_updated_atとして記録し、サイトマップ・構造化データ・article:modified_timeへ反映する。ネイティブの更新日時の方が新しければそちらを保持する。未変更記事の日付を一斉に新しくしたり、未来日を出したりしない。元の公開日・保存済み更新日・本文・指紋は維持し、読者向けの本文内に日付説明を増やさない。1.46.0から1.46.1へ配布。
