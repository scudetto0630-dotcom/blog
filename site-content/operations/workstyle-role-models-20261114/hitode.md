# ヒトデの詳細分析

参照先：[今日はヒトデ祭りだぞ！／hitodeblog](https://www.hitode-festival.com/)

主に参考にする部分：親しみのある体験談と、解説・申込みページの役割分担

## 更新状況と確認範囲

雑記ブログには2026年の記事がある。解説サイトには11月13日の更新表示もあり、活動停止ではない。

新規記事は雑記側、更新表示は別の解説サイト側。混ぜてブログ全体の新着日としない。

根拠：[D01：今日はヒトデ祭りだぞ！](https://www.hitode-festival.com/) / [D07：ペットロスの本を全国に届けるための告知](https://www.hitode-festival.com/?p=16240) / [D11：WordPressブログの始め方](https://hitodeblog.com/wordpress-start)

## 1. 一人で複数の場所を運営（分析）

雑記ブログは本人を知る場所、hitodeblogは初心者が具体的に学ぶ場所、ABCは継続的な支援の場所として読める。四人のうち一人だが、分析する媒体は一つではない。全部を雑記ブログ単体の売上として捉えると誤る。

根拠：[D01：今日はヒトデ祭りだぞ！](https://www.hitode-festival.com/) / [D08：hitodeblog：ブログの始め方](https://hitodeblog.com/) / [D09：hitodeblog側のプロフィール](https://hitodeblog.com/about-hitode) / [D10：ABCオンライン](https://abc-space.jp/abconline)

## 2. 読者ごとの入口（分析）

雑記には仕事・趣味・暮らしなどの入口がある。解説サイトには知りたいことや段階ごとの案内がある。人物への関心と、今すぐ方法を知りたい目的を、同じ導入だけで満たそうとしていない点が参考になる。

根拠：[D01：今日はヒトデ祭りだぞ！](https://www.hitode-festival.com/) / [D08：hitodeblog：ブログの始め方](https://hitodeblog.com/)

## 3. 体験記事の導入（分析）

感情や率直な本音で入り、読者が聞きたいことへ進む。退職後の年数を区切った記事は、一度の出来事を後から違う問いで振り返っている。毎回同じ退職話を再掲することとは違う。

根拠：[D03：仕事を辞めてフリーランスになってから1年が経ったよ！](https://www.hitode-festival.com/?p=6673) / [D04：ブログで仕事辞めて4年が経ったので振り返ってみる](https://www.hitode-festival.com/?p=14038)

## 4. 笑いの作り方（分析）

自分の行動や大げさな自己評価にツッコミを入れて、説明の緊張を緩める。強い言葉や叫びの量だけを真似ると、あなたの話より演出が先に立つ。実際に語った気持ちや少し抜けた行動があるところだけ軽く崩す。

根拠：[D03：仕事を辞めてフリーランスになってから1年が経ったよ！](https://www.hitode-festival.com/?p=6673) / [D06：ヒトデの2025年を振り返る！！！](https://www.hitode-festival.com/?p=16098)

## 5. 本音と一般化の境目（分析）

本人は会社との相性を強く語るが、会社員にも向き不向きがあると書く。あなたの方針では会社批判を弱め、安定を重視した過去を残す。自由な勤務時間や収入が全員に実現するかのような説明も持ち込まない。

根拠：[D03：仕事を辞めてフリーランスになってから1年が経ったよ！](https://www.hitode-festival.com/?p=6673) / [D04：ブログで仕事辞めて4年が経ったので振り返ってみる](https://www.hitode-festival.com/?p=14038)

## 6. 厚い実用記事の作り方（分析）

解説サイトは、全体の流れ、具体的な手順、画像、動画、関連記事を組み合わせる。長さだけでなく、読み手が止まるところに別の説明がある点が参考になる。ただし調査した長大な開設記事は導入・手順の入口までで、全編の正確性を検証したわけではない。

根拠：[D08：hitodeblog：ブログの始め方](https://hitodeblog.com/) / [D11：WordPressブログの始め方](https://hitodeblog.com/wordpress-start)

## 7. 実画面で確認できたデザイン（観察）

hitodeblogのトップは生成り色の背景と暖色のカード、同じキャラクターでまとまる。PCは本文とプロフィールの2列、スマホは入口カードが2列で本文は1列。画面幅1440pxと390pxで横はみ出しはなかった。これは解説サイトの観察で、雑記側のデザインとは分ける。

根拠：[D08：hitodeblog：ブログの始め方](https://hitodeblog.com/)

## 8. 実測できた文字と技術（観察）

取得した解説トップの段落はPC17px・行高33.15px、スマホ15.5px・行高27.125px。背景はrgb(247,242,232)。CSSパスにはWordPressテーマjinrがある。これは観測したページ・幅での値で、全記事の統一仕様や最適値ではない。

根拠：[D08：hitodeblog：ブログの始め方](https://hitodeblog.com/)

## 9. 広告につなぐ方法（分析）

サーバー開設の解説記事にPR表示、料金・クーポン、手順への入口がある。方法を説明するページの中で、その実行に必要なサービスへ進む設計。実際に購入・登録があったか、クリック率がどの程度かは外部から分からない。

根拠：[D11：WordPressブログの始め方](https://hitodeblog.com/wordpress-start)

## 10. 複数の収益源（分析）

本人の年次振り返りでは、アフィリエイト、コーチング、創作・出版、ABC等を扱う。ABCの販売ページには料金と募集停止の案内がある。過去の最大月収・累計収益を、今の特定ブログの毎月の利益に読み替えない。支援金も利益とは別。

根拠：[D06：ヒトデの2025年を振り返る！！！](https://www.hitode-festival.com/?p=16098) / [D07：ペットロスの本を全国に届けるための告知](https://www.hitode-festival.com/?p=16240) / [D09：hitodeblog側のプロフィール](https://hitodeblog.com/about-hitode) / [D10：ABCオンライン](https://abc-space.jp/abconline)

## 11. 更新頻度と事業の変化（分析）

本人は2025年の振り返りで、発信事業の維持と別の活動について語っている。新規記事の頻度が低くても、既存の解説を更新する運営がある。量を増やすだけでなく、読者が使う手順を現状に合わせることが学べる。

## 記事ごとの組み立てを分解する

完成記事の分析。著者が実際に使った制作工程を断定するものではない。

### 本音と相性で読ませる振り返り

対象：[仕事を辞めてフリーランスになってから1年が経ったよ！](https://www.hitode-festival.com/?p=6673)

入口：退職して一定の時間が経ったことから、率直な感情を出す。

展開：会社と自分の相性 → 独立後の暮らしと収入 → 今の働き方が合う理由とこれから

読む理由：強い感情を読ませる一方、すべての人が同じではないと述べる。具体的な生活の話が結論を支える。

結びと案内：関連する過去記事・他の活動へのリンクがある。体験談全体を一つの登録ボタンに置き換えていない。

こちらで使うなら：読みやすい本音を使う。会社が嫌いという著者の感情を、安定を重視していた本人に移さない。

### 同じ転機を違う時点で捉え直す

対象：[ブログで仕事辞めて4年が経ったので振り返ってみる](https://www.hitode-festival.com/?p=14038)

入口：当時の決断を思い返し、その後どうかという読者の疑問へ進む。

展開：辞めてよかったか → 準備や試したこと → 今後何を大切にするか

読む理由：前の記事に続く時間の変化が新しい内容になる。経歴が同じでも、問いと答えが更新される。

結びと案内：過去記事へのカードと、本人が今後どうするかという結び。実際の回遊率は不明。

こちらで使うなら：小出しの経歴は前回のあらすじで水増しせず、今はどう考えるかを追加する。

### 活動の全体像から収益の窓口を知る

対象：[ヒトデの2025年を振り返る！！！](https://www.hitode-festival.com/?p=16098)

入口：年末の振り返りを、軽い自分へのツッコミを交えて始める。

展開：コーチングの活動 → 創作・出版の活動 → ブログや他の事業の振り返り

読む理由：人物への関心がある読者に、複数の活動をまとめて見せる。直接サービスへの関心を持つ入口にもなる。

結びと案内：書籍の購入先や活動への案内がある。本人の2025年の説明から現在の収入内訳は確定しない。

こちらで使うなら：ある程度の記事と経験がたまったときに、働き方の振り返りを作る参考。事業や実績を無理に増やさない。

### 読者の行動を支える実用記事

対象：[WordPressブログの始め方](https://hitodeblog.com/wordpress-start)

入口：読者ができることと、全体の手順を早めに示す。

展開：必要な作業の全体像 → 画像・動画による補助 → 必要なサービスと手順への案内

読む理由：読者が次に何をするか分かるよう、説明方法を複数用意する。調査範囲は長大な本文の入口まで。

結びと案内：PR表示・サーバーの料金案内・クーポンを確認。本文末尾全体と申込み完了は未検証。

こちらで使うなら：転職サービスでも、登録後に何が起きるかを具体化する発想を使う。ただし公式の現行情報を別途確認する。

## 取り入れること

- 体験談と比較・手順記事の入口を分ける
- 自分への軽いツッコミで読みやすくする
- 読者が今いる段階に応じて次の記事を示す
- サービスを使う場面を説明してから紹介する

## そのまま取り入れないこと

- 強い会社批判や叫びの大量再現
- 複数事業の収入を一つのブログの利益と扱う
- クラファン支援金を通常の利益と扱う
- すぐに別サイト・LINE・有料コミュニティを増やす

## 未確認のこと

- 広告ごとの成約率・流入元
- 有料コミュニティの現役会員数・利益配分
- コーチングや創作の現在額
- 雑記ブログ側のPC・スマホ実画面
