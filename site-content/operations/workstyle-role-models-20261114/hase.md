# はせおやさいの詳細分析

参照先：[インターネットの備忘録](https://hase0831.hatenablog.jp/)

主に参考にする部分：気持ちの変化と、どちらの働き方も尊重する文章

## 更新状況と確認範囲

ブログ先頭は2026年4月。更新間隔は長いが、noteなど別の発信窓口も存在。活動終了と断定しない。

ブログの先頭で確認。noteは相対日付が混じり、全媒体の最新日は確定しない。

根拠：[H01：インターネットの備忘録](https://hase0831.hatenablog.jp/) / [H02：あたらしく社会人になるひとへ 2026](https://hase0831.hatenablog.jp/entry/20260402)

## 1. 人物とブログの役割（分析）

会社員として暮らしながら書く人の個人ブログ。仕事だけに閉じず、家庭・読書・日常の変化が文章の背景にある。前に紹介した独立から会社員へ戻る文章は、本人ブログの記事ではなくマイナビ媒体への寄稿。媒体の所属を混ぜない。

根拠：[H01：インターネットの備忘録](https://hase0831.hatenablog.jp/) / [H06：自由を求めてフリーランスになり、会社員としてふたたび組織で働くまで](https://meetscareer.tenshoku.mynavi.jp/entry/20210415-hase0831) / [H10：はせおやさい note](https://note.com/hase0831)

## 2. 読者との距離（分析）

完成した成功法則より、経験して迷い、考え直す人の文章として読める。読者に同じ人生を選ばせるより、自分の選び方を考える余地がある。想定読者の分析であり、実際の読者の年齢・職業を調査したわけではない。

根拠：[H02：あたらしく社会人になるひとへ 2026](https://hase0831.hatenablog.jp/entry/20260402) / [H04：50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041) / [H06：自由を求めてフリーランスになり、会社員としてふたたび組織で働くまで](https://meetscareer.tenshoku.mynavi.jp/entry/20210415-hase0831)

## 3. テーマの見つけ方（分析）

読んだ文章への引っかかり、過去の自分、暮らしの変化が入口になる。技術や仕事内容を細かく明かさなくても、一つの見方が変わった理由を掘れば記事になる。本人の業務内容を伏せたい今回の希望に合う。

根拠：[H03：戦略的がむしゃらに挑戦しよう](https://hase0831.hatenablog.jp/entry/202512040900) / [H04：50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041)

## 4. 導入から結びまで（分析）

きっかけ→過去の考え→今の違和感→気づいたこと、という流れが見える。すぐに万能な結論を作らず、途中の考えも説明する。一方、手順記事や広告比較で同じ長い内省を続けると目的が見えなくなるので、ジャンルに応じて使う。

根拠：[H03：戦略的がむしゃらに挑戦しよう](https://hase0831.hatenablog.jp/entry/202512040900) / [H04：50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041)

## 5. 経歴を小出しにする方法（分析）

過去記事へのリンクが、そのときの自分と現在を結ぶ。昔の出来事を毎回全部書き直さず、その記事で必要な意味を加えられる。あなたの場合も、安定を重視していた頃の一場面と、今の一つの変化から始めるのがよい。

根拠：[H03：戦略的がむしゃらに挑戦しよう](https://hase0831.hatenablog.jp/entry/202512040900) / [H05：逃げろ、そして生き延びろ](https://hase0831.hatenablog.jp/entry/20121002)

## 6. 文章と感情の扱い（分析）

仕事で得たものと失ったもの、以前の方法と今の限界を併記する。共感を得るために、相手や昔の自分を単純に悪者にしない書き方が学べる。強い体験の文章は、本人が経験したことが前提。あなたの退職理由や心身の不調に置き換えない。

根拠：[H04：50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041) / [H05：逃げろ、そして生き延びろ](https://hase0831.hatenablog.jp/entry/20121002)

## 7. 働き方を比較する姿勢（分析）

寄稿では、独立してから気づいた組織の助けと、自分に合う環境を述べる。結論はあなたと逆でも、判断の過程は参考になる。本人の結論を逆向きに書き換えて自分の話にするのではなく、比べる観点を得る。

根拠：[H06：自由を求めてフリーランスになり、会社員としてふたたび組織で働くまで](https://meetscareer.tenshoku.mynavi.jp/entry/20210415-hase0831)

## 8. 記事の見せ方と回遊（分析）

公開抽出では、本文、プロフィール、過去記事、カテゴリ、読者登録、外部活動への案内がある。大量の比較表やランキングが中心ではない。ただし現行の列構成・フォント・色は画面未取得で不明。はてなが表示する更新なし広告を、本人の広告収入と扱わない。

根拠：[H01：インターネットの備忘録](https://hase0831.hatenablog.jp/) / [H02：あたらしく社会人になるひとへ 2026](https://hase0831.hatenablog.jp/entry/20260402) / [H08：四十にして惑いまくりの日々を綴る日記、始めます](https://hase0831.hatenablog.jp/entry/20230601-15)

## 9. 直接の収益化と外部への広がり（分析）

本人が書く仕事を得た経緯を公表しており、ブログが執筆の実績にもなる。電子書籍や外部への寄稿に加え、codocの有料記事への入口も確認。全てをアフィリエイトで稼ぐモデルとまとめるのは不正確。

根拠：[H07：ブログを書き続けていたら、夢が叶った話](https://hase0831.hatenablog.jp/entry/2016/04/15/010801) / [H08：四十にして惑いまくりの日々を綴る日記、始めます](https://hase0831.hatenablog.jp/entry/20230601-15) / [H09：身辺雑記を書き続けてきた理由――ブログとわたし](https://blog.hatenablog.com/entry/2020/07/02/170000)

## 10. 有料部分へのつなぎ方（分析）

codocの記事は、誰のどんな日常を読むか、なぜ公開するかを説明し、無料部分から続きへ進む。無料の導入は内容を予告する役割を持つ。ただし依頼記事でもあり、購入者数・売上・報酬の有無と額は確認できない。

根拠：[H08：四十にして惑いまくりの日々を綴る日記、始めます](https://hase0831.hatenablog.jp/entry/20230601-15)

## 11. 古さや未解決の話との付き合い（分析）

過去の文章を後から参照できる強さがある反面、十年以上前の体験を今の一般的な労働環境と混同しない。書き手の立場も時間とともに変わる。記事単位でいつ、どの立場の話かを内側で管理する必要がある。

根拠：[H03：戦略的がむしゃらに挑戦しよう](https://hase0831.hatenablog.jp/entry/202512040900) / [H05：逃げろ、そして生き延びろ](https://hase0831.hatenablog.jp/entry/20121002) / [H07：ブログを書き続けていたら、夢が叶った話](https://hase0831.hatenablog.jp/entry/2016/04/15/010801)

## 12. こちらのブログに移す方法（こちらへの応用）

最も役立つのは「昔はこう思った、経験してここが変わった」を読ませる部分。仕事内容の開示を増やす必要はない。読者の不安に寄り添う文章と、制度やサービスの事実を伝える説明をつなぎ、全記事を重い告白や有料日記に寄せない。

根拠：[H02：あたらしく社会人になるひとへ 2026](https://hase0831.hatenablog.jp/entry/20260402) / [H04：50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041) / [H06：自由を求めてフリーランスになり、会社員としてふたたび組織で働くまで](https://meetscareer.tenshoku.mynavi.jp/entry/20210415-hase0831)

## 記事ごとの組み立てを分解する

完成記事の分析。著者が実際に使った制作工程を断定するものではない。

### 短い助言にも、時間の積み重ねを持たせる

対象：[あたらしく社会人になるひとへ 2026](https://hase0831.hatenablog.jp/entry/20260402)

入口：過去の記事を参照して、環境の変化に触れる。

展開：昔と違う働く環境 → 自分のペースを知る話 → 長く働く読者への短い言葉

読む理由：新しい読者にも分かる内容の中で、長く考えてきた人だと伝わる。過去の経験を丸ごと再掲しない。

結びと案内：特定サービスへ登録させる結びではない。読者登録などのブログ標準の案内がある。

こちらで使うなら：本人の固定軸を毎回長く説明しなくても、過去記事へのつながりで人物像を育てられる。

### 成功法則が変わる過程を読む記事

対象：[50歳を前に、スキルの天井が見えた](https://hase0831.hatenablog.jp/entry/2025/11/10/121041)

入口：別の記事を読んだことから、最近の自分の悩みに進む。

展開：以前に力を入れたこと → 暮らしが変わり同じ方法が使えないこと → 今の自分が試そうとしている考え

読む理由：きれいに解決した話でなくても、理由と変化があれば読める。仕事内容の詳細より選び方と気持ちに焦点がある。

結びと案内：万能な成功法則を売る結びではなく、考えている現在の状態を残す。

こちらで使うなら：安定に対する考えの変化にも応用できる。まだ本人が語っていない悩みを、読者受けのために増やさない。

### 自分と逆の選択にも理由を残す

対象：[自由を求めてフリーランスになり、会社員としてふたたび組織で働くまで](https://meetscareer.tenshoku.mynavi.jp/entry/20210415-hase0831)

入口：複数の働き方を経験した立場から、組織で働く魅力を話す。

展開：独立した理由 → 経験して気づいた自分の特性 → 読者が自分の望みを考える方法

読む理由：結論は会社員への復帰だが、独立も否定しない。判断の過程を読む価値がある。

結びと案内：マイナビ媒体の寄稿で、末尾に関連解説へ進むリンク。本人ブログの広告収益とは別。

こちらで使うなら：あなたの結論を逆にする必要はない。同じように自分の条件を説明し、読者の結論は読者へ残す。

### 誰の日常を読むのかを伝える有料記事

対象：[四十にして惑いまくりの日々を綴る日記、始めます](https://hase0831.hatenablog.jp/entry/20230601-15)

入口：依頼記事であることと、日記を始める理由を示す。

展開：自分の年代や立場 → どんなことを記録したいか → 無料の一部を示し購入の境界へ

読む理由：有料だから有益なノウハウだけにするのではなく、人物への関心で読まれる内容を説明している。

結びと案内：codocの購入境界を確認。有料本文、価格の現行条件、売上は未確認。

こちらで使うなら：無料部分で内容が分かる設計は学べる。ただし今のブログを有料日記へ変える方針ではない。

## 取り入れること

- 過去と現在の考えの違いを理由とともに書く
- 仕事のよさと難しさを同じ人物の視点で残す
- 経歴は過去記事へつなぎ、必要な場面を少しずつ出す

## そのまま取り入れないこと

- 本人の病歴・家庭・葛藤の流用
- はてなの広告を運営者の収益と即断する
- 寄稿先の記事を本人のブログ広告記事と混ぜる
- 今回の読者の目的と違う長い内省や有料日記の一律導入

## 未確認のこと

- 広告・有料記事・印税・寄稿それぞれの実収入
- codocの購入者数・現在の価格と購読条件
- 本人が受け取る広告分配の有無
- 他媒体を含めた最新の活動日
- PC・スマホの実画面・色・寸法
