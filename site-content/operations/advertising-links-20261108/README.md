## 根拠と注意

- 毎日口健は犬猫兼用のミルク味粉末のみ。猫用錠剤と取り違えない。公式画像の一部には別商品名の誤記があったため使わず、商品と配合が一致する画像を選択した。
- 毎日習慣の個別ページは200でもPHPコード片66bytesだけだったため本文根拠にしない。取得できた公式商品一覧と猫用パッケージ画像で確認できる形状・内容・配合だけを採用。給与量の境界や詳しい成分量は推測しない。
- ほかの猫用サプリも粉末・犬用とは別に確認。副作用なし、疾病が治る、減量や視力回復を保証する説明は追加しない。
- 医薬品や療法食とサプリを区別し、活性炭と薬の組み合わせは獣医師へ相談する案内にした。個々の猫への投薬・給与量を指示しない。
- PHP/JSONの生データと原本画像は非公開の作業領域に保存。公開リポジトリには自分で整理した根拠JSONと出典・指紋を記録した。
