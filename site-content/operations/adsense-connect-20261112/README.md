# AdSenseのサイト接続

所有者がAdSenseアカウントを作成し、サイト追加後の所有権確認画面を提供。表示された公開者ID `ca-pub-1945643191231022` の接続コードを設置する。

- Googleが示した非同期スクリプトとcrossorigin属性を保持し、公開ページのheadへ一度だけ出力。検索結果・404・端末内の保存一覧・プレビューなどは対象外。
- `/ads.txt` をWordPressの仮想テキスト経路でHTTP200配信。同じ公開者IDのDIRECT行とGoogleの認証局IDを返す。既存ファイルは事前確認で404だった。
- プライバシーポリシーにGoogleの広告サービスと広告設定・情報利用の公式リンクを追記。元の固定ページ本文を上書きせず、当該ページだけに表示する。
- デザイン・記事本文・写真・公開日・ホーム設定は維持。広告枠の挿入や自動広告設定の変更は行わない。
- 日次の広告点検で、コードの重複と公開者IDに対応するads.txt行の欠落を検出する。

バージョン1.40.1を固定コミット・SHA256・更新前バージョン1.40.0を指定して配布。HSH_EDIT_TOKENは出力しない。

公開後にHTTP応答、head内のコード、ads.txt、PC/スマホ表示、記事指紋を確認する。ブラウザ検証は第三者通信と書き込みを遮断し、実際の広告表示や広告クリックは行わない。Google側の所有権確認と審査リクエストは所有者のログイン画面で実施する。コード設置を、審査承認や収益発生と同一視しない。
