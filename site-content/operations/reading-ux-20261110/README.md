## 修正
- 保存・続きを読むを表に残し、読了・本文検索・文字サイズ・履歴設定を「読むためのツール」にまとめる。データと既存の操作ハンドラーは維持。
- 各見出しの「リンク」を小さな # 表記へ変更。44pxの操作面積と具体的な読み上げ名を維持。
- ウイスキーメモの目次を銘柄カードの外へ移動。
- 新規のセット画像・銘柄画像も写真ビューアーで拡大できるようにする。
- 記事内検索をEnter・Shift+Enterで前後移動できるようにし、空にしたとき強調と件数を解除。操作パネルや記録シートの文章は検索対象から除外。
- 上へ戻るボタンを写真の拡大中・フッター表示中は隠し、端末のセーフエリアを考慮。
- PCヘッダーのスクロール前後の高さを固定し、縮むことによる読み位置のずれを防ぐ。
- 読書位置の計算は記事の寸法と見出し位置をキャッシュし、スクロールごとのレイアウト取得を減らす。リサイズ・記事の寸法変更・文字読み込み後に更新する。
- バスカー緑の画像を、本人の追加依頼で既存と同じ写真調で生成し、感想カードへ追加。生成画像の表示・台帳・ハッシュを記録。
