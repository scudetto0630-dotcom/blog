# 公開画像注記の削除とグレンファークラスの訂正

本人から、画像下・本文に生成注記を出さないよう再指定があった。ウイスキーカードのハードコードした注記、リベットのセット画像の注記、リベット・ファークラスの本文の生成注記を削除。台帳の42素材の代替テキストも通常の内容説明へ変更する。内部のkind・生成履歴・出典は保持し、実際に購入した現物の撮影写真という説明は加えない。

グレンファークラス12年は、本人の提示したクリーム色ラベル・赤いロゴ・青い筒箱を基準に生成し直した。記事の表紙・一覧カード・ウイスキーメモに同じ正しい商品デザインを使用。新しいファイル名と480px派生で旧画像のキャッシュを避ける。ほかの既存画像は保持。

全42記事の本文と指紋を照合して保存。本文の変更はリベットとファークラスの2記事の注記削除と代替テキストのみ。画像URL・リンク・公開日・タイトルは保持する。配布は既存バージョン1.38.10・固定コミット・ZIPのSHA256を照合。

公開前：Python64件・PHP1166件成功。指定を忘れた注記の再追加を検出する回帰検査を追加した。公開後に全公開投稿・固定ページとトップ・カテゴリーを走査し、スマホ・PCの表示と新画像のハッシュを確認する。
