# 自己紹介の道具名の列挙を削除

本人の指摘を受け、トップの自己紹介とプロフィールから道具名の列挙や「抽出を頼むと速くて、本当に楽」という説明を外した。以前はMR、現在はフリーランスでデータを扱う仕事、仕事を変えるまでの迷いや働き方を書く、という内容へ整えた。プロフィールには既に回答済みの、約1年・知人の紹介・経験に合う仕事という事実を使用。具体的な手順を説明する記事の製品名までは変更しない。

トップ設定内のHTML属性に入っていた余計なバックスラッシュを除去し、既存の写真とリンクを正しい属性で保持。元の公開日・URL・他の設定・他の記事は変更しない。公開前の状態はbefore.json。
