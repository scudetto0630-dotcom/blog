# 審査待ち中の読者導線改善

ユーザーはAdSense審査待ちの画面を提示し、今できる改善の継続を依頼。現在のデザインを維持する。

## 確認した問題

公開されたラベル解説・CSV等の記事で、本文末の関連記事、追記されたおすすめ枠、別の関連記事枠が同じ行き先を繰り返していた。目次にも「あわせて読みたい記事」が繰り返し出ていた。検索実績によるタイトル試験ではなく、実際の公開画面で確認した読みやすさの問題として対応する。

## 変更

既存のテキストだけの関連記事枠が複数ある記事で、最初の枠の位置へ一つにまとめ、URLの重複を除く。異なる行き先は保持し、リンクの表示名は現在公開されている記事タイトルに合わせる。本文の段落・出典・数値・写真・広告URL・計測画像は書き換えない。画像やフォームを含む枠、外部リンクを含む枠、既存IDがある枠は触らない。一つだけの関連記事枠も維持する。

元の投稿データは上書きせず、表示時の既存フィルターで処理する。元の公開日・URL・写真・記事指紋、トップのデザイン、AdSense接続コード・ads.txtは維持する。新しい体験談や検索順位は作らない。

所有者提供済みのSearch Console出力を確認。検索語の表は0行で、28日ずつの比較期間も不足しているため、検索語・CTRに基づくタイトル変更は行っていない。記事を増やせば収益が出る、導線変更で閲覧数が増えた、とは結論しない。検索データの全文は非公開の作業領域に保持。

プラグイン1.40.2を固定コミット・SHA256・更新前バージョンの照合で配布し、公開後に関連記事・内部リンク・PC/スマホ表示と広告接続を確認した。
