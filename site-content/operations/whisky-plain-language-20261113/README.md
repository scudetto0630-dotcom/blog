# ウイスキー記事を初めて読む人にも伝わる表現へ修正

本人指定：「40%の通常版」は不要。数値にはアルコール度数と書き、知らない人が多い別仕様をわざわざ持ち出さない。トフィーなど説明なしの専門語を見直し、全て確認する。承認済みチャートのデザインは保持。

全7銘柄の本文・種類表・推薦文・展開式のチャート根拠を確認した。アルボラリスの導入は「アルコール度数は40%。自分が5本目に買ったウイスキーだ」とし、「通常版」を削除。価格の段落も容量・箱・送料だけで比べる文へ直す。別仕様の発売時期など、今回の本文に不要な説明は加えない。

全てのトフィー表現を「砂糖とバターを煮詰めたお菓子のような甘い風味」などに置き換える。メーカーの香味紹介を分かりやすく言い換えたもので、本人がそう感じた体験として追加しない。フィニッシュは飲んだ後に残る風味、酒質は味わい、プラム・トロピカルフルーツはスモモ・南国の果物へ。モルト・グレーン・ポットスチル・精溜器・酒精強化ワインも、使う箇所で意味が分かるように補う。ポットスチルの原料はDrinks Ireland掲載のHMRC技術資料でも確認：https://www.ibec.ie/drinksireland/-/media/documents/drinks-ireland-new-website/irish-whiskey-technical/irish-whiskey-verification---hmrc.pdf

仕様表の見出しは「アルコール度数・容量」。各銘柄の産地・樽・年数・度数・容量そのもの、価格例・出典・チャートの数値は変更せず、修正前との比較で確認する。本人の購入順・購入時価格・好き嫌いも保持する。

更新前に通常URL・確認用クエリ付きURLを読み、双方HTTP200、前回指摘された「なるほど気になる造り」は既に消えていた。一方「通常版」「トフィー」は実際に残っていたため修正対象にした。スクリーンショットが古い理由を推測でブラウザーや利用者に帰さない。公開後も通常URLの全文を、閉じた補足まで含めて検査する。

AGENTS.mdと既存の配布手順に従い、1.45.2から1.45.3へ固定コミット・配布ZIP SHA256・更新前バージョンを照合して配布。URL・写真・公開日・保存済み本文・指紋を保持し、同梱プロフィールの表示だけを修正する。新規投稿なし。トークンの値は表示しない。
