## 出典の確認方法と限界

公式商品ページ・制度ページ・販売ページを対象に確認。実行環境からの取得は一部のホストでプロキシの接続拒否になったため、対応する公開Web取得でも照合した。環境の取得失敗を、販売サイトの404や記事のリンク切れとして扱わない。ページの取得成功と、個々の主張が裏付けられたことは別。

HARIOの商品規格、Catlogの料金・特典、国税庁の所得・経費・個人事業者、厚生労働省の雇用・有休・フリーランス法、公正取引委員会の対象と取引条件、健康保険・年金、ウイスキーの商品規格・樽・受賞情報等を公式資料で点検。価格・在庫・制度の個別適用を保証しない。全文の研究控え、問い合わせ確認、Search Consoleの生データは非公開領域だけに置く。

Search Consoleは既存接続を利用。受信済みの検査対象ではクロール・インデックス許可に問題を示す結果はなかったが、全URLの登録を保証するものではない。タイトル実験の基準に足りる検索表示はなく、少数の結果を根拠に需要やCTR改善を断言しない。
