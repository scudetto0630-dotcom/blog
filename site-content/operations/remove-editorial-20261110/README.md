# 不要な記事・広告ページを撤去

本人の依頼で、記事・広告について（ID30）をゴミ箱へ移し、トップ・フッター・プロフィール・ブログ紹介記事・更新一覧・検索補助から導線を削除。プロフィールへの本文移植や転送は行わない。旧URLは404。元の内容は公開せず操作前の控えに保存する。

既存の認証付きpage操作で、editorialキー・管理対象・現在の指紋が一致する場合にだけtrashを許可。WordPress標準のwp_trash_postを使う。他ページの削除や指紋なし・競合時は拒否する。

各広告記事の広告表示・A8リンク・計測画像・記事本文は変更しない。プラグインは固定コミット・SHA256・既存1.38.12の照合で配布する。
