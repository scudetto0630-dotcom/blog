# 100項目の点検・改善（2026年11月8日）

利用者の操作や追加素材を必要としない100項目を点検。対応表は「100項目対応表.md」、機械可読版は checklist.json。既存機能の確認を含み、新規100機能の追加ではない。

## 今回の修正

- 商品19件に表示用商品名を追加。記事タイトルが混ざって長く不自然だった購入先ボタンを、短い商品名＋公式案内へ統一した。リンク先・追跡画像は変更していない。
- 体験談3記事と商品記事の指示語・重複・定型句を個別改稿。写真・リンク・本文の数値を保持。CTA内に正式商品名を入れたため「110」「PS-B1」の数字が増える箇所はある。
- 検索語の全角数字・CSV・空白を正規化し、不正な配列入力を処理しないようにした。
- 絞り込み等の44px操作領域、動きの軽減、強制カラーモード、印刷時の広告非表示を補強。
- 記事内写真の再試行対象を拡張。同一サイトの画像だけを再取得し、1px画像や外部広告への再送信を避ける。
- 商品リンク19件の掲載URL・位置・状態・確認日時をJSON/CSVに記録。これは運用台帳であり、不要と指定された練習CSVをサイトへ追加するものではない。
- 公式参照先の監査に最終URL・本文サンプルの指紋・販売終了等の確認候補を追加。HTTP 200だけで在庫ありとは扱わない。
- 校正台帳の点検時刻を固定日付から実行時刻に修正。校正・商品管理の回帰テストを定期CIへ追加。
