# 7銘柄のウイスキー記事を補強

依頼：実体験を中心にしつつ、全ウイスキーに産地・原料・製法・歴史・熟成樽・種類・市場価格・評価・おすすめを加える。話し口調を保ち、6項目の10点スケールの六角形チャートを掲載する。

対象は本人が飲んだ7銘柄。既存5記事（グレンリベット12年、グレンファークラス12年、通常版アルボラリス、ジムビーム白、フロム・ザ・バレル）に製品の背景を追加し、陸とバスカー緑は独立記事を作る。オーチャードハウスはボトル未購入のため、既存の「次に気になる」紹介に留め、飲んだ採点は作らない。IT記事の追加体験を作る作業ではない。

## 調査と表現

製品・歴史・製法はメーカーと日本の輸入元を優先。原料や樽は各商品の資料で確認し、同じ会社の別商品の仕様を流用しない。グレンリベットのダブルオークをシェリー後熟と断定しない。バスカー緑はモルト・ポットスチル・グレーンのブレンデッド、ジムビームはバーボン。通常版アルボラリスは40%で、カスクストレングスとは混同しない。グレンファークラスの全期間オロロソシェリー樽熟成は輸入元の製法紹介を根拠とする。陸の輸入原酒とノンチルフィルタード（常温ろ過あり）を保持。陸・フロムの詳細な樽構成や未公表の熟成年数は推測で埋めない。

フロムの公式ブランドは51.4%、国内商品案内は51%表記。数字の差の理由は未確認のため勝手に説明せず、両資料に合わせて表示。マリッジ、1985年発売、ISC2015のトロフィーを確認。グレンリベット12年のSFWSC2026ダブルゴールドは現行公式ページで確認。別仕様の受賞や曖昧な口コミ点数を使わない。フロムの高騰は過去の専門メディアの記事を資料とし、本人の3,900円で戻ってきた印象を市場全体の統計にはしない。

香りの果物やキャラメルを全て本人が感じたようには書かない。メーカーの香味表現を紹介する文と、本人が実際に語った感想を分ける。購入順、歴史的購入価格、苦手だった感想、好きな香り、こぼれるボトルの話を残す。性別による推薦や架空の体験は加えない。

## 価格と図

価格は同じ通常仕様・容量で販売店の商品ページを比較し、税込商品代の掲載例としてリンクする。市場の最安値や在庫の保証ではない。送料、取寄せ、時期による違いを記す。本人の購入時価格とは別枠。2026-11-13に資料を確認したが、Web取得のキャッシュには過去のクロールが含まれるため、今現在の在庫を保証しない。取得できなかったカクヤス（HTTP403）や酒のいろは・させ酒店（HTTP503）は価格例の根拠から外した。製造元Glenfarclasの画像主体ページは補完として読み取れた輸入元の説明を使用する。

6軸は煙たさ（ピート）、フルーティーさ、甘み、樽の香ばしさ、コク、余韻。0〜10で編集上の推定値を置き、各軸の理由を展開表示に記す。実測、本人から回答された数値、口コミ平均ではない。特に煙・余韻は情報不足の推定を明記。樽の焦がし香とピートを同一視しない。面積や点数を品質順位にしない。SVGと6つのテキスト値・meterで表示し、JavaScript不要。読み上げ名と各点の説明を付ける。

## 保存・配布

AGENTS.mdと既存の編集・配布手順を適用。作業前の認証status/content-status/starter-status、46投稿・9ページの本文等を私有work領域へ保存。HSH_EDIT_TOKENは環境から読むだけで値を表示しない。既存記事の原文・指紋・日付を上書きせず、対象slugの描画時に同梱の検証済み情報を加える。追加2記事はcontent-releaseでexpected:nullを指定。既存写真と章ID・URLを保持し、他ジャンル・広告・A8計測は変更しない。

プロフィールは既存reader-content-map.jsonへ追加し、描画ヘルパーとCSSも既存ファイルへ追加。陸・バスカーの画像は既存の対応画像を使い、生成に関する内部記録を保持する。配布400ファイル制限を維持。plugin 1.45.0を、固定コミット・リモート配布ZIPのSHA256・expected_version:1.44.0で配布する。
