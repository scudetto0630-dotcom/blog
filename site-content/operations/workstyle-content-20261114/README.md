# 働き方の記事改稿・5本の新規記事

本人の回答に基づき、既存IT4記事を改稿し、働き方の比較・解説5本を追加する。元のURLと公開日、既存の写真、無関係な記事は保持する。

主記事は「正社員が一番だと思っていた自分が、今は個人事業主を選んでいる」。正社員→生活の変化で派遣→悩んでいた時期に知人の紹介→個人事業主、という経緯を保存。正社員の制度を魅力的に思う瞬間もあるという本音を残す。全記事で職歴を一から繰り返すのではなく、テーマに必要な範囲で紹介する。

4人の調査から、体験から比較へ進む構成、一つの記事で一つの疑問に答える構成、具体的な条件を見てサービスを選ぶ導線を応用。固有の体験・文体は転用していない。

## 制度情報の確認

plan.jsonに参照URL、記事のsource_urlsにも個別の参照先を保存。国税庁で事業所得・必要経費・給与所得控除を確認。数値例は架空と明記し、一律の税率や手取り率は使わない。厚生労働省で有給休暇は正社員限定ではないこと、派遣元との雇用関係、契約名だけで労働者性が決まらないことを確認。協会けんぽ・日本年金機構で退職後の切り替えを確認。公正取引委員会の案内で取引条件の明示と、適用対象に応じた原則60日以内の支払いを確認し、例外・対象条件も記載。

追加資料：
- https://www.mhlw.go.jp/general/seido/anteikyoku/haken/01a.html
- https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6109.htm

J-Net21の比較ページは検索結果で確認できたが、取得した本文ではナビゲーションが中心だったため、個人事業者の定義には本文を確認できた国税庁の案内を採用した。

## 公開手順

認証付きAPIで現在の本文・指紋を.private/workstyle-content-20261114に保存。既存のbundle3記事は公開指紋と改稿前ソースの指紋が一致することを確認。CSVは現在の公開本文を元に写真を保持したpayloadを使用。新しい5本と既存bundle3本はcontent-release、CSVだけはmanaged-articleで、現在の指紋を条件に保存する。

プラグインは固定コミットとSHA256で配布し、バージョンを確認した後に本文を公開。公開後の結果はverification.jsonに記録する。運営用の収益化提案はMONETIZATION.md。
