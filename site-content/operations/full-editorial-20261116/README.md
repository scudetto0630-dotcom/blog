# 全記事の再校閲と働き方の記事追加

依頼日：2026-11-16。固定する軸は「正社員が一番だと思っていた自分が、今は個人事業主を選んでいる」。公開前の本文控え、指紋、取得した参考記事の全文は私有領域に保存する。

## 対象と判断

公開中の53記事（保存済み49記事、管理対象の初期3記事、紹介記事1本）、9固定ページ、記事に追加表示されるウイスキー7銘柄の説明と商品29件の案内を点検。非公開の「記事・広告について」は復活させない。問題のないタイトルまで変更することを目的にしない。各記事の確認結果は `review-ledger.json` に記録。

あひるねこさんの記事は、疑問や期待から入り、具体的な違いを確かめ、感想と結論をつなぐ構成の参考。固有の口調、言い回し、体験を転載・再現しない。本人が話していない失敗、収入、休暇、保険の選択は補わない。

実際に掲載されていた本文を取得すると、アルボラリスの古い銘柄表記等が残っていた。保存データとの差を記録し、本人が確認したアルボラリスの銘柄と、グレンファークラスを選ぶ場面を優先して直す。既存の公開日、写真、見出しID、広告リンクと計測画像は照合する。

## 追加済み5本の構成

|記事|今回の読み順|
|---|---|
|正社員と個人事業主|契約の違い→自分がほしい自由→お金・休日・保険→自分の安心|
|フリーランスと個人事業主|経験のある派遣→個人事業主→フリーランス→実態と契約→選ぶ条件|
|売上と手取り|40万円から5万円を引く例→売上・入金・所得→経費→支払日→年間比較|
|転職か働き方の変更か|派遣の時期にも悩んでいた経緯→変えたい部分→転職・独立の条件→相談→自分の答え|
|契約前に見るところ|契約相手→担当範囲→報酬と支払日→場所・時間→終了条件→使える道具→相談先|

写真は直後の見出しと一緒に移動。経歴を毎記事の冒頭に貼り直さず、段落ごとに話を進める。正社員を下げる結論にしない。

## 新規3本

- `freelance-days-off`：休みを選ぶことと、休んでも収入が変わらないことを分けて考える。
- `freelance-health-insurance`：国保・任意継続・家族の扶養の比較、任意継続の期限、年金の別手続き。
- `freelance-contract-renewal-end`：更新・終了・最後の報酬・引き継ぎ。30日前予告の適用条件と例外を含める。

既存の比較記事では短く触れていた疑問を、各記事の中で具体的に解決する。9枚の新規素材を内部台帳に記録し、各記事は表紙1枚と本文2枚。各画像に600px版を用意し、所有者の実際の机や契約書として説明しない。公開ページへ生成注記を追加しない。
