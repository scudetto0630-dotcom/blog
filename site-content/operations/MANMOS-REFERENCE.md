# まんもすの写真を使うとき

ユーザーが提供した猫本人の写真が基準。新たな生成はモデルの学習完了ではなく、参考画像付きの画像生成として扱う。

- 2026-10-26の追加写真では、正面の顔、緑がかった目、ピンクがかった鼻の中央の濃い模様が分かりやすい。
- 長い茶色の毛、頬と首まわりの淡い色の毛、丸い顔、写真どおりの耳の形を保つ。品種名だけから耳を極端に折りたたまない。
- 光による毛色や目の色の違いを、別の模様や青い目として作り足さない。
- 参照するなら assets/photos/manmos-front.webp、manmos-lying.webp、manmos-portrait.webp、manmos-back.webp、manmos-sitting.webp が顔・横顔・全身を補える。
- 提供写真を再生成して「本物の写真」と呼ばない。generated/providedの区別と短い説明を保持。
- 通院・商品の使用・購入などの実体験は、生成した場面から作らない。写真から健康状態も診断しない。

追加分では3枚を採用。プロフィールを正面写真に変更し、まんもすの記事へ横になった姿・座った姿を追加。元の写真は上書きせず、公開用WebPは向きの補正と縮小・圧縮のみ。EXIFは保持しない。画像生成の追加実行はしていない。
