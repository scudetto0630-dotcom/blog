# 全42記事の日本語と導入の見直し

2026-11-10の「全部の記事直していこう」と、体験談の不自然な価格・味の説明への本人指摘に対応。対象は既存の専用3記事、同梱10記事、広告29記事の合計42記事。今回は全記事の導入と、重複・回りくどさがある段落を見直す。全記事の全段落を全面改稿したという意味ではない。

商品紹介は商品名・用途・読む内容を先に示し、「同じではない」「分けて考えたい」と繰り返す前置きを減らす。価格・商品仕様・対象動物・療法食／サプリと治療の区別、給与量、服薬中の相談など、購入や健康の判断に必要な内容は保持。正式名・数値・原材料・A8リンク・計測画像・広告表示・出典と確認日を維持し、新しい使用体験や効能を足さない。資料の再調査による仕様・価格更新ではない。

グレンファークラスは「当時は約6,500円だった」で購入当時の価格と分かるようにし、現在価格の断りを重ねない。味はまろやかさ、ストレートのかすかな刺激、ハーフロックでの飲みやすさを直接書く。43度と刺激の因果関係を持ち出して否定する説明は削除。重複していた12年という数値表現の回数は減るが、商品や度数・価格は変更しない。

本人から追加確認した、まんもすを迎えるまでの経緯も反映。迎える1か月前、室外機の裏で鳴いていた子猫を保護してカカオと命名し、当時は引き取れず動物病院に預けた。毎日気になっていたが素敵な飼い主さんが迎え、自分もやはり猫を引き取ろうと決めた。シェルターへ行った日は誰かを迎える決意があり、大きなまんもすをひと目見て「この子だ」と感じた。持参したキャリーが狭く、当日別の物を購入。病院名・事情・新しいキャリーの仕様や価格は補完しない。約1年前の6,000円のリュック、10年以上前のキャリーと同一とは決めない。まんもす紹介記事と迎える準備の記事の「準備で困らなかった」も、この具体的な経験に置き換えた。

迎える準備の記事では、本文全体を囲んでいた関連記事navを末尾の実際の関連記事部分だけへ修正。既存アンカーとリンクは保持する。

更新前の全42記事は、タイトル・原文・抜粋・表紙IDから再計算した指紋と認証付きAPIの指紋の完全一致を確認して保存。WordPress保存時のHTMLエンティティ正規化も照合した。`site-content/backups/natural-japanese-20261110/articles-before.json` は一致を確認した原文。公開HTMLとテストの詳細は私有作業領域へ保存。

専用3記事は `merge_paragraph_corrections` で現在の公開原文へ段落修正だけを適用し、既存の画像を保持。キャリー原文に既にあった非表示のHSH_IMAGEコメントは新たに追加したものではない。メディア更新用revisionは変えず、画像の再取込みを誘発しない。ほか39記事は既存のcontent-releaseを使う。版1.38.5のZIPは固定コミット・SHA256・現行1.38.4を照合して配布し、本文は更新直前の指紋が一致する場合だけ書き込む。

公開結果と画面確認は verification.json に記録する。厳格textlint設定は変更しない。固有名詞や本人の感想、ラベルの文末などの機械候補は意味を確認し、候補の数を減らす目的で文章を不自然に分割しない。
