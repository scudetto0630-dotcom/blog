## 集計と操作

- WordPress「外観 → 広告リンクと月次記録」で確認できる。利用者側の設定操作は不要。
- 広告リンクへの通常の移動を妨げず、外部サービスへ個人データを送らない。DNT/GPCを尊重。
- 日別のクリック通知は90日、月次記録は12か月。送信抑制用の秘密鍵付き一時キーは1分。
- 公開プライバシーポリシーにも匿名集計の説明を追加。
- WP-Cronはアクセスをきっかけに実行されるため、定時の実行保証はない。
- 管理者の本人確認、Search Console実績、追加写真は今回要求していない。
