# ウイスキーチャートの明色化と項目順の修正

本人指定：暗いチャートの色がサイトに合わない。フルーティーさを上、煙たさを下へ移す。ブレンデッド、シングルモルトの後はウイスキーを省略しない。

背景を生成り、文字を深いグリーン、線と塗りをグリーン系に変更し、暗いネイビーとブルーを外す。数値カードも生成りに合わせる。上から時計回りに、フルーティーさ、甘み、コク、煙たさ（ピート）、スパイシーさ、余韻。内部の原データの並びは保存し、表示時に数値と理由を一緒に並べ替える。ラベルだけを入れ替えて違う数値を表示しない。スマホ・PCで軸の位置と数値の対応を検査する。

全7銘柄の本文・種類欄を「ブレンデッドウイスキー」「シングルモルトウイスキー」にそろえる。スコッチ、アイリッシュの区分は括弧で示す。後から加わる用語説明や関連記事も対象記事内で表記を統一。既に正しい正式表記に「ウイスキー」を二重に足さない。原料・樽・価格・感想・データのスコアは変更しない。

既存のURL・保存済み本文・指紋・公開日・写真を保持し、同梱プロフィールと描画・CSSを更新する。APIで現状の指紋を保存し、plugin 1.45.1を固定コミット・ZIP SHA256・expected_version:1.45.0で配布する。新しい記事の追加公開はない。HSH_EDIT_TOKENの値は表示しない。
