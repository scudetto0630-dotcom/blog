# 表示広告と検索流入の運用開始

本人はAdSense未作成。受託作業・営業を増やさず、既存ブログを表示広告と検索流入で育てる方針。現在のデザインは維持する。新しい体験談を捏造しない。

## 今回実施

- 認証付きsite-audit・engagement-statusで現状確認。表示広告スクリプト・公開者IDなし。広告売上は取得していない。
- 公開点検は失敗0。読者導線・構造化データの点検は問題0、孤立記事0、内部リンク3034件を確認。
- 削除済みの編集方針ページを正常ページとして要求していた3点検・2ブラウザテストを修正。公開HTTP点検では404を正しい状態として明示し、ページの再出現を検出する。HTTPエラー時に実際のコードを保持するよう修正。
- 広告の導入状況を調べる読み取り専用ツール `tools/revenue-readiness.py` を追加。問い合わせ・自己紹介・プライバシー・robots・サイトマップ・ads.txtを確認。AdSense開始前のads.txt未設置はエラーにしない。
- 既存の日次GitHub Actionsに広告点検と結果のartifact保存を追加。設定の追加であり、GitHub上の定期実行成功は今回確認していない。自動執筆・自動改善の常駐処理を開始したわけではない。
- 所有者提供済みのSearch Console ZIPを再確認。直近の対象期間は22日分、前期間0日分で比較不可。自動接続はなく、検索順位・CTR・流入増加は判定していない。独自の到達件数にはキャッシュ・点検アクセス等の影響があり、PVや自然検索流入として使わない。

## 次に必要な本人操作

https://adsense.google.com/start/ から本人のGoogleアカウントで申し込み、サイトに `https://hirogarushumi.com/` を指定する。支払先の国・本人情報・規約同意などは本人が判断・入力する。Googleが接続用コードを発行したら、その公開用コードまたは公開者IDを受領してサイト側へ設置する。パスワード・認証コード・住所・口座情報をチャットで受領しない。
