# 文と段落のつながりの修正

利用者の指摘：「細かくセンテンスで分けられて読みにくい」。前回は参考記事の構成を整理した一方、実際の校正を短い言い切りへ寄せ、段落と表示のつながりの確認が不足していました。

句点ごとに自動で段落を作る処理はありませんでしたが、短い文の連続、導入直後の要約ボックス、本文途中の関連記事カード、広めの段落余白が重なっていました。

## 変更

- 29記事を修正。20段落で、理由・動作・結果が自然につながる言い回しへ書き直しました。
- 同じ話題が続いていた17か所は段落を統合。見出し・写真・表・重要な注意をまたぐ一括結合はしていません。
- 自動の「この記事で分かること」ボックスを導入の途中へ挿入する処理を削除。通常の目次は維持。
- 本文途中の関連記事カードを本筋の後へ移動。
- 冒頭の文章を独立した囲みから通常の本文表示に戻し、段落の余白を調整。

## 例：グレンリベットの記事

以前は、買った決め手、何本目か、飲んだ感想を短く切って並べていました。修正後は、以下のようにきっかけから感想へつなげています。

> 自分でウイスキーを買い始めて3本目に選んだのが、グレンリベット12年だった。きっかけはグラスのおまけだったけれど、飲んでみると飲みやすさだけでなく、花に鼻を近づけたときのような上品な香りも気に入った。

文章を長くすることも、短くすることも、それ自体は目的にしません。意味が続くところはつなぎ、話が変わるところで段落を変える方針を、今後の文章基準へ反映しました。

## 保持したもの

タイトル、見出しとID、数値、商品情報、参照URL、広告リンクと計測画像、既存の写真・図。専用3記事は公開本文へ差分を適用し、元データの画像差し込み記号で図を上書きしません。

公開日と実表示は公開後に検証します。検証結果はverification.jsonに保存します。
