# 本文の日付を自然な言い方へ

2026-11-10の本人指定。「2026年10月時点で5歳」のように本文へ管理用の基準日を入れず、「現在5歳」と書く。迎えた時期は「25年の春」、白州見学は「25年の夏」とする。精密な撮影・体験時期はバックアップと管理記録で保持する。

全42カタログ記事とブログ案内投稿、専用固定ページ、本文へ自動で加わる表示を確認した。変更する原稿はキャリー、猫を迎える準備、まんもす、パウズグリーンデリ、ジャガーの5記事。商品価格の本文は「確認したときの価格」とし、正確な調査日は出典欄の一か所へ残す。申込期間・資格の年齢判定日などの実務上必要な日付は変更しない。

プロフィールと白州見学ページも、現在の公開原文から日付表現だけを修正する。白州の写真説明に繰り返していた年月を削り、展示・メニューが訪問当時のものだという案内は残す。画像URL・alt・寸法・srcsetは維持。写真マニフェストはキャプションだけを変更し、画像ファイル・出典・種別・ハッシュは変更しない。関連するウイスキー写真一覧、見学ページの紹介文・補助見出しにも同じ表現を使う。

記事上部に公開日・更新日があるので、全42記事の本文末尾の重複する「本文の見直し」日付を出力しない。購入ポイント欄でも日付を重ねず、元からある出典欄へ一本化する。WordPressの公開日・更新日、構造化データの日付、内部の確認・撮影記録は保持する。

更新前は認証付きstatus / content-status / starter-reviewを取得。全42記事の原文・タイトル・抜粋・表紙IDから計算した指紋がAPIと完全一致した。専用固定ページの指紋も再計算して照合。控えを site-content/backups/natural-dates-20261110/ に保存した。

キャリーの修正は本人指定の日付数値の削除を伴うため、数値不変が条件のmerge_paragraph_correctionsは使えない。現在の指紋と変更対象の一文が一致することを確認し、その一文だけを置換して画像タグ・リンクを照合する。既存の校正関数の制約やテストを緩和しない。
