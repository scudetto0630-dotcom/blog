## 働き方の入口

既存の `/category/it-freelance/` を使い、本人の体験記事の次に、以下の疑問から記事を選べる入口を置く。新しい重複ページは作らない。

- 転職か独立か迷っている：転職と働き方の変更、正社員との比較、呼び方の違い、ITで最初に迷ったこと。
- お金や休みが気になる：売上と手取り、休日・有給休暇、退職後の健康保険。
- 仕事を受ける前に知りたい：契約前の条件、更新・終了・最後の報酬。

データの扱い方の記事は、同じ入口の折りたたみから読める。リンクはJavaScriptに依存せず、公開状態の実際の記事タイトルで表示する。

## 本人の体験

2026-11-16の追加回答を、核となる体験記事と、転職・働き方の比較記事へ反映。家族や周囲の環境から会社員が普通だと思っていたこと、転職で感じた違和感、30歳目前でやりたいことを優先して派遣を選んだこと、2年半続けても芽が出なかった後の不安を記す。

2年半を派遣の在籍期間とは扱わない。周りと比べて進歩していないと感じたのは本人の気持ちであり、客観的な評価として断定しない。目指していたこと、現在の年齢、周りの結婚・出産などは創作しない。詳しい経緯は体験記事に置き、全記事へ繰り返さない。

## 読み終わった後

働き方・ITの記事12本に、内容に合わせた次の2本と、読む理由を付けた。売上の記事から健康保険や契約へ、契約前の記事から更新・終了へ進める。最新記事という理由だけで別の話へ送らない。既存の本文中のリンク・写真・公開日を維持する。

既存の「知りたい内容から読む」には、CSVの見出しを別の記事のURLに結び付けていた不具合があったため、実際のCSV記事へ直した。公開サイト全体のリンク検査で再確認する。

## スマホの読み込み

同じトップ画像に600px版を追加し、画像とpreloadが同じ候補・表示幅を使うようにした。大きい画像を先に余計に読み込むことを防ぐ。原画像は維持。追加測定で大きかった仕事カテゴリーの写真と体験記事の表紙にも600px版を用意し、計3枚のスマホ用画像を追加した。

独立したカテゴリー用テンプレートでは、フロントページと同じく不要なテーマのCSSを読み込まない。記事ページやお問い合わせのフォームには、この変更を広げない。配色と既存デザインを保つ。

実測は390px、キャッシュ無効、CPU4倍、下り180,000bytes/s・遅延100msという同じ条件。広告等の第三者リクエストは両方で停止。実ユーザーのCore Web Vitalsや、順位改善の証拠とは扱わない。公開後の画面・リンク・転送量の確認は `verification.json` へ記録する。
