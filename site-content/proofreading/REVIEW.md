## 文脈・意味を読んで修正した点

| 以前の表現 | 修正内容 |
|---|---|
| シングルモルトが好きで、特にシェリーカスクが好み | ウイスキーの種類と熟成に使う樽を区別し、2文で説明 |
| 「00123」のまま必要なことがある | 識別番号の先頭の0をデータとして残す、と述語を明確化 |
| 猫と敷物を合わせて持つ | 猫の体重にキャリー本体と敷物の重さが加わる、と対象を明確化 |
| 今は個人事業主になり | 現在の状態を説明する「個人事業主として」に統一 |
| 好きなお酒はシングルモルトで、特にシェリーカスク | シェリー樽で熟成させたシングルモルトウイスキーと説明 |
| 底板を外せるか。角を拭けるか。 | 確認する動作まで含めた文に修正 |
| 銘柄、分量、氷。それに一言感想があれば | 何を記録するのかを述語のある文で説明 |
| 空欄を渡す | 空欄を含むデータを取り込んだときの処理、と具体化 |
| 何から学べばよいかという経験の説明 | 過去の戸惑いと現在の業務内容を分けて記載 |
| 調べたことや、個人事業主として働くことをまとめる | 調査内容をまとめることと、ブログのテーマを分けて説明 |
| 7チェック／家ハイボール | 画像を「7つの確認」「ハイボールの作り方」に修正 |

助詞の連続、数字の表記、読点の多い文も点検した。
正確な内容を断定へ変えてツールを通さない。未確認の経験・購入歴・試飲記録は追加しない。
お問い合わせは案内文だけ、プライバシーポリシーは重複見出しと「広告を配信する事業者」という表現だけを表示時に修正。
保存されたフォームのショートコードやプライバシー条項の内容は変えない。

自動校正は自然さの保証ではない。今回の記録を、全文章に誤りがないという保証として扱わない。
