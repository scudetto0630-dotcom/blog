- `掲載管理.csv`：24行。スプレッドシートにインポートできる。受領日、資料受領日、確認日、掲載先、状態、公開日を管理。公開前は掲載URLと公開日を空欄にする。
- `links.json`：元のA8コード、計測URL、実際の遷移先、管理IDを保持。商品リンク生成でもトップページへ飛ぶ場合は、そのことを記録する。
- `記事/`：13件の原稿。未使用の情報紹介で、既存記事に合わせた約1,600〜1,700字、7節と確認表。
- `research.json`：提供資料の取得状況・確認記録・SHA256。公式ページをこの環境から再取得できたとは扱わない。
- `構成案/`：保留案件の検討メモ。完成記事ではない。
- `hsh-collect-v2.ps1`：修正版の取得補助。旧版は初期化できず後続行が実行される問題があったため除去。

掲載条件は利用者が確認済み・特別な条件なしと回答。商品の使用歴、効能、改善、注文・到着の体験は創作しない。健康に関する商品は治療の代替として紹介せず、公式の成分・形状と確認点を区別する。口コミを管理人の体験として使わない。

広告記事は冒頭で広告と未使用を明示し、A8のURL・計測画像を維持。広告リンクにnofollow/sponsoredを付ける。URLのみ受領した4件は受領URLのアンカーを作成し、未提供の計測画像は推測で足さない。検証時はA8の計測リクエストを送らず、クリックもしない。

写真は既存のまんもすの実写。今回の13件ではカバーをそれぞれ変え、各記事のカバーと本文2枚も別々にする。旧記事・写真一覧で使う実写を再利用するが、商品を使用した証拠として扱わず、本文で使用写真ではないと説明する。旧13記事の写真割当と原稿は変更しない。

公式説明の確認上の注意：毎日美肌の成分数の表現には列挙との不整合があるため、数を転載せず成分名のみ照合。毎日良肝の保存HTMLには別商品の記述が混在しているため、冒頭の毎日良肝のタイトル・descriptionにある情報のみを使用。腎臓向け商品とは書かない。

公開後に実際の記事URL・WordPressの公開日時を記録し、管理画面にもA8管理ID、元コード、参照資料、未使用であることを登録する。個人用の管理メモと生の取得HTMLはプラグインに同梱しない。
