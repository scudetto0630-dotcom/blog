# 画像追加・文章改訂（反映待ち）

公開中の3記事のURL・カテゴリーを維持して改訂します。

- カテゴリーの紹介と、この最初の記事を読む導入を追加。
- 説明書のような語尾の繰り返しを減らし、読者に語りかける文章へ改稿。
- 体験、試飲、商品使用実績を捏造しない。個人の職歴・猫の飼育歴は既に確認されたもののみ。
- タイトル入りのアイキャッチ3枚＋本文図解3枚。image_genで作成し、文字・図の内容を視認確認。
- 図はリンクで原寸表示可能。トップページの画像は16:9・切り抜きなし。
- WordPressの専用3記事に限る更新API、変更前指紋検証、履歴10件、メディアの再利用を実装。
- 今後のこの3記事の文章修正は `managed-article` 接続で可能。任意の記事・プラグインファイル・ユーザー権限は操作できない。

検証：PHP-WASM＋WordPressスタブ68件成功。画像本体のPNG署名・寸法・SHA256を確認。3記事×PC1440/スマホ390/320のローカルプレビュー9件で画像読み込み・文字コード・横はみ出しを確認。実WordPressの画像処理は未検証。

現時点の公開サイトには反映していません。1.3.0へ更新後、次の順で実行：
1. `starter-review` で既存本文と指紋を取得し、手動編集の有無を確認。
2. `starter-image` で記事に対応する表紙・本文図を各1枚ずつ登録（計6枚）。
3. 各slugの指紋をexpectedに指定し `starter-refresh` を実行。
4. 公開3記事の本文・画像・アイキャッチ・トップページを検証。

公開中の原文は ../ のJSON、今回の改訂版はこのディレクトリのJSONとプラグイン内 starter-articles.json に保存。
