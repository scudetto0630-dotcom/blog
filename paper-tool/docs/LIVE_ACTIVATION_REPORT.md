## 実装
- 既存Pythonエンジンと入力・製品・履歴画面を継続使用。
- EGCGに加え、エピカテキン、クルクミン、ビタミン類、アミノ酸等の日本語別名から検索名へ変換。任意の英語検索名を受付。未知の日本語名と同一成分の別名重複は入力エラー。

- 別の有料Web Service＋永続ディスクを作る `render-live.yaml` を追加。既存root Blueprintと静的サイトは維持。
- 実サーバー確認後に元URLを案内先へつなぐ設定を追加。旧IndexedDBは消さず、?provided=1で元の画面に戻れる。
