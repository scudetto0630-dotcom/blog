# 提供された実データの読み込み

公開画面の「提供データを使う」でZIP/TXTを複数選択し、「資料を読み込む」。
現在の入力・製品管理・履歴・デモ画面は維持し、実データ閲覧は独立した画面にしています。

対象資料:
- 仕分け前.txt
- chatGPT仕分け.zip
- 僕が仕訳けた.zip
- ティグリーン.zip

資料自体をGitHubや公開サイトへ埋め込みません。利用者のブラウザのWeb Workerで展開し、PMIDで重複除去してIndexedDBへ保存します。同じ公開URL・同じブラウザで再利用できます。資料読み込みは最大100MB、展開250MB・3000ファイル・入れ子4段の検査上限があります。資料のテキストを命令として実行しません。

## できること

- 実際の日本語/英語タイトル、年月、PMIDによる検索。
- EGCG/カテキンの絞り込み、50件ずつの一覧。
- 人間版掲載、AIの提案、製品別参考分類、使用しないフォルダを区別。
- 人間版にない論文は「判断未確認」で、除外確定にしない。
- 人間版のタイトルと図リンクを保持。51分類外の名称は勝手に変換しない。
- ZIPを実生成。51分類のファイルとヒト試験ファイル、要確認、除外未確定の説明、READMEを出力。
- ファイルを発表年月の新しい順にし、PMIDで重複除去。

## 検証済み

提供された4ファイルをPlaywrightで実際に読み込んだテスト15件が成功。PMID24,292件、人間版102件、カテキン21,182件を確認。更新保持、不正ZIP、ZIPダウンロード、4画面幅も検証。
生成ZIPのCRCと、全51分類のPMIDを人間版と突合して一致を確認。

## 未実装

この機能は提供済み資料の閲覧・整理です。新たなPubMed取得、学習済み分類器、科学的判定、2回の独立再チェックを実施していません。人間版のヒト試験判断をそのまま出典付きで保持し、科学的な裏付けを新たに検証したとは表示しません。カテキンの参考資料を人間の正解扱いにせず、EGCGの人間判断をカテキンへ流用しません。

全自動の本番エンジンは別途実装が必要です。有料APIは実行していません。

## テスト

`node tests/research-browser.cjs` はこの実資料が実行環境のattachmentsにある場合の操作テストです。個人資料を公開リポジトリにコピーしません。
`python -m unittest discover -s tests -p test_teacher_ingest.py -v` は小さな合成入力でオフライン解析の構造と安全性を検証します。合成入力を学習・正解の代用品に使っていません。

ZIP処理ライブラリ: fflate 0.8.3 (MIT)。配布コードとライセンスを `app/static/vendor/` に保持。
