## 発見・修正した不具合

1. **編集中の更新で未保存入力が上書きされる**: 編集・履歴再利用の画面で保存済みデータを再取得した際、ローカル下書きが失われた。下書きの画面・編集状態を保持し、同じ画面の未保存入力を優先するよう修正。再テスト成功。
2. **採用フィルターの選択肢が欠ける**: optionタグの閉じ方が誤っていた。HTMLを修正し、採用・除外を実際に選択して結果件数を確認。
3. **日本語の共有パスワード比較**: 標準の定数時間比較へ非ASCII文字列を直接渡すとエラーになる。UTF-8バイト列で比較するよう修正し、認証テスト成功。

任意入力欄の空欄は保存・開始時に省略し、空白だけを入力した場合は拒否するよう入力仕様を整理しました。テスト準備で下書きが残る問題は、テスト側を明示的に再読み込みして分離するよう修正しています。
