ひろがる趣味暮らし トップページ 1.0.0

導入
1. WordPressとデータベースのバックアップを取得する。
2. プラグイン > 新規プラグインを追加 > プラグインのアップロード で ZIP を導入し、有効化する。
3. 外観 > ひろがるトップページ > トップページを適用。
4. 必要ならキャッシュを削除し、トップページと記事ページを確認する。

変更範囲
- cats / whisky / it-freelance のカテゴリーがなければ作成。
- 独立した固定ページを新規作成し、トップページに設定。
- この固定ページだけ専用テンプレートを使う。他ページは従来のテーマ。
- 公開済み記事をカテゴリー別に3件ずつ表示。既存記事のカテゴリーは変更しない。
- 既存記事、既存固定ページ、テーマファイル、メニューは編集しない。
- 原設定は hsh_original_front に保存。

復元
外観 > ひろがるトップページ > 元のトップページ設定に戻す。
プラグイン無効化でも、トップページが本プラグインのページなら元設定を復元。
作成ページとカテゴリーは残す。第三者が別のトップページを設定した場合は上書きしない。

検証状況
PHP 7.4 構文解析、および同じCSS・ヒーローの静的HTMLでPC/スマートフォン表示を検査。
実WordPressでの適用・復元、Cocoonや他プラグインとの統合は未検証。
実サイトへのアクセス・編集認証が利用可能になった後の確認が必要。

注意
既存の運営者情報・お問い合わせ・広告掲載方針は自動作成しない。
既存フッターメニューは専用トップページでは表示しない。
プライバシーポリシーが設定済みならリンクを表示。
記事のカテゴリーが未設定なら各一覧は空。架空の記事・実績は表示しない。
