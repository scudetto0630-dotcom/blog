# ひろがる趣味暮らし

WordPress 用のトップページプラグインです。猫・ウイスキー・ITの仕事とフリーランスの3カテゴリーを入口にします。

## ダウンロード

[プラグインZIPをダウンロード](https://github.com/scudetto0630-dotcom/blog/raw/refs/heads/main/hirogaru-home.zip)

リポジトリが非公開の場合は、GitHubにログインしてから開いてください。
上のリンクで保存できない場合は、リポジトリ内の `hirogaru-home.zip` を開き、右上の **Download raw file** を押してください。
GitHub の Code > Download ZIP はリポジトリ全体のZIPなので、そのままWordPressには導入しないでください。

## 導入

1. WordPress・データベースをバックアップ。
2. WordPress「プラグイン > 新規プラグインを追加 > プラグインのアップロード」で `hirogaru-home.zip` を選択。
3. インストールして有効化。有効化だけではトップページは変わりません。
4. 「外観 > ひろがるトップページ > トップページを適用」。
5. キャッシュを削除し、トップページ・記事ページ・スマートフォン表示を確認。

元に戻すには「外観 > ひろがるトップページ > 元のトップページ設定に戻す」。
無効化時も、本プラグインのページがトップページなら元設定を復元します。
既存記事、テーマ、メニューは変更しません。新規ページとカテゴリーは復元後も残します。
