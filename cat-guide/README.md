2026-10-16、運営者の正式リリース指示に従って仮称・制作中の表示を削除。通常ページはindex/follow、404はnoindex。canonical・OGPと16URLのsitemap.xmlを生成し、WordPressのrobots.txtにサイトマップを追記する。プラグイン停止で配信も停止する。

- 段階別の入口、カテゴリ＋段階＋キーワードの複合検索。既存URLと保存済みチェックリストのキーを維持。

- `/health/` に緊急連絡と日常の健康管理の案内を分けた。病名判定機能ではない。
