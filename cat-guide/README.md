# 猫の情報サイト（別プロジェクト）

サイト名「ねこより西東京」。個人運営、拠点は西東京。保護・譲渡団体や診療サービスではない。

## 開発と更新

- 原稿：`content/articles.json`（6記事）。構成・固定ページ：`tools/build.py`。
- デザイン：`assets/style.css`。操作：`assets/site.js`。外部ライブラリ・有料API不要。
- `python cat-guide/tools/build.py` で13HTML（12ページ＋404）と素材を生成。
- 起動：`node cat-guide/tools/serve.cjs（127.0.0.1:8025）`。
- テスト：`python -m unittest discover -s cat-guide/tests -p 'test_*.py' -v`、`CAT_GUIDE_URL=http://127.0.0.1:8025/ node cat-guide/tests/browser.cjs`。
- チェックリストはlocalStorage保存。問い合わせ送信、寄付受付、アクセス解析、広告は未設置。
- 検索はサイト内だけの検索。自治体・保護団体の最新情報を外部検索する機能ではない。

## 既存ConoHaでの正式配信

`python cat-guide/tools/package_preview.py` で生成物と限定ルーターを既存専用プラグインに同梱する。
`/neko-guide/` だけを配信し、WordPressのホーム・記事・分類・既存データを変更しない。
既存の認証済み専用プラグイン更新経路を使う。新しいパスワード・有料ドメインは不要。
2026-10-16、運営者の正式リリース指示に従って仮称・制作中の表示を削除。通常ページはindex/follow、404はnoindex。canonical・OGPと12URLのsitemap.xmlを生成し、WordPressのrobots.txtにサイトマップを追記する。プラグイン停止で配信も停止する。
ファイル配信は生成した明示的許可リストに限定。PHP・manifest・任意パスを公開しない。
静的ZIPをConoHaの別ディレクトリへ設置する構成にも移せるが、現在SFTP・管理画面の接続はない。

このチャットでの依頼に応じてCodexが更新できる。チャット外で毎日自動執筆する仕組みや常駐エージェントは導入していない。将来の自動更新も、健康情報は根拠の確認ができない記事を自動公開しない。
