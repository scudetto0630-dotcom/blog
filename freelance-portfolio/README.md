# WORK & CODE

PC向けのフリーランス個人サイト。ビルド・外部ライブラリー・APIキーは不要です。

`index.html`をブラウザーで開くと閲覧できます。開発時はこのディレクトリーで`python -m http.server 8766 --bind 127.0.0.1`を実行してください。既存プロジェクトのファイルは変更していません。
